###### 变量

变量理解为一个容器，比较常见的当做容器的做法是交换顺序
> 学了数据结构之后我把他理解成了一个栈,但是只能进一个特殊的元素

~~~ c
#include <stdio.h>

int main(void){
	int a = 24;
	int b = 42;
	int c;
	
	//将 a 容器的水装到空杯 c 里面
	c = a; 
	//将 b 容器的水装到 a 里面
	a = b;
	//将 c 容器的水装到 b 里面，从而达到交换a b 值的目的
	b = c;
}
~~~

有些东西和理论知识中的定义类似，可以通过赋值来改变变量的内容，但是不能够重复定义变量，第一次定义变量我们又叫**初始化**

 ###### 整数溢出

int 是 4 个字节，他的范围大概是 ∓ 2³¹ - 1，只要你储存的变量超出这个值，就会发生整数溢出的现象，可能会影响整个程序，很多游戏是使用的 int 存储整数类型，修改器改到 2147483647，程序就会显示为负数（除了游戏对这一部分设置了最大只的限制），原因如下
~~~ text
十进制最大值 2147483647
机器一般识别的是二进制
二进制 01111111 11111111 11111111 11111111
二进制默认最左边为0， 1 表示正,负，0 为正，1 为负数，只要比 int 的最大值+1，就会得到：
二进制 10000000 00000000 00000000 00000000
整数溢出时，表示正负的部分被占用了
~~~

 ###### 固定宽度格式输出
 
 > 企业常用 <stdint.h> 的文件来表示变量类型，但很少用 %d , %lld, 什么的在 printf 里去输出，因为复杂（需要记忆加上输出可以自定义就导致麻烦看不懂），所以使用了 <inttypes.h> 来格式输出
~~~ c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void){
	int8_t num = INT8_MAX;
	
	uint32_t unum_1 = UINT32_MAX;
	
	int64_t num_2 = INT64_MAX;
	
	printf("num max = %" PRId8 "\n", num);
	
	printf("unum_1 max = %" PRIu32 "\n", unum_1);
	
	printf("num_2 max = %" PRId64 "\n", num_2);
	
	return 0;
}
~~~
 里面 PRId32 就是 %d 了，对于复杂的 %hhd 什么的就可以增加可读性

 > //初始化像素：游戏像素加载最快加载出 123 ，这是最小值，要求速度，不考虑内存
 > int_fast32_t screen = 123;

###### 浮点型

浮点数可以理解为实数，包含整数只不过加了小数点，在计算机中，浮点数存储是分为两部分的：**小数部分**与**整数部分**
比如 3.14159
 [浮点数计数模式](https://zh.wikipedia.org/wiki/IEEE_754) IEEE 754 frank 里面是选修，可以解释溢出，进位等等

| +   | .314159 | 10¹ |
| --- | ------- | --- |
| 符号  | 小数      | 指数  |

也可以说三个部分

 ###### float

 一般在数据后面加个 f 来表示是 float 类型，来提醒程序员这是浮点数输出，可能存在精度丢失，注意什么类型就用什么格式，浮点数与整数相乘就会发生格式转换
 ~~~
 float speed = 23.23f;
 printf("%f", speed);
 ~~~
 >因为计算机存储数据是使用二进制，有些浮点数用二进制表示是无限循环小数，所以会表示出精度丢失的现象
 
 ~~~
 浮点数的其他输出方式：
 %e/%E: 科学计数法表示;
 %a/%A: 十六进制表示又叫P计数法
 ~~~
 overflow 与 underflow
 超出 float 的最大值，直接溢出，会输出 inf（infinity 无穷)
 比 float 小，CPU 会识别不出是什么值，数的后面几个部分是乱的
 > nan （not a number)
 > inf（infinity)
 > 例子如下：
  
 ~~~ c
  #include <stdio.h>
  #include <float.h>
  #include <math.h>
  int main(void){
  
  	float infinity = INFINITY;
  	printf("%f\n", infinity); // 正无穷
  	
  	float fu_infinity = -INFINITY;
  	printf("%f\n", fu_infinity); // 负无穷
  	
  	float num = 1.0f;
  	float infi = num / 0.0f;
  	
 	printf("%f\n", infi); // 无穷
  	printf("%f\n", sqrt(-1.0f)); // 开-1的平方不是一个数
  
 	return 0;
 }
 ~~~
 
 ###### double

 #double 精度比 float 高，输出用 %f 或者 %lf ,在浮点数类型中，double 与 float 是共用一个输出的（严谨点就是 %f 会默认将数值上升到 double)，数据如果不在后面加 f ，默认是double 类型
 long double：精度比 double 高，数据后面需要加上 L，用 %Lf 输出（默认输出==**六位**==）
 float 一般用于有速度要求的东西，比如3D图形渲染

##### char型

char 的话只能输出一个字母或者符号，用 **%c** 输出
==本质上是存储的一个 int32 整型== （用 %c 输出 int32 中 128 以内的数字会表示出字母或者控制符号），就是说定义的 char 先转换成整型，然后再转换为二进制储存在计算机中。
规定在 [ASCII码](https://www.runoob.com/w3cnote/ascii.html) 里面，其中 0-31 和 127 为控制字符（能实现一些控制类的功能，如回车，换页什么的），剩下的 32-126 则是字母与一些符号，小写字母与大写字母差 32。
