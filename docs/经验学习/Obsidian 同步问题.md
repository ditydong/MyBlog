# 2026-10-27

## 发生了什么

计划用 Github 上的教程同步一下电脑和平板的内容，因为我下定决心要学习，安装插件没问题，其实这本质就是插件，但是我卡在账号登陆上，因为我的账号绑定的是我妈妈的手机好，这导致了我不能够登陆。
## 我原本以为

电脑上直接，用平板上的代码，然后直接登陆，或者直接修改密码，然后用密码登陆
## 实际发现

不行，这几个方法都行不通，代码在电脑上依旧需要再次登陆，就是绕回了平板上无法登陆的问题，密码修改了现实不是正确的密码
## 为什么
因为就是微软账号的安全性问题，还有就是历史遗留问题，之前登路微软账号的时候，就是直接更妈妈打电话问的，后面考虑过更改手机号绑定但是忘了

## 我的经验

- 首先，试过行不同的问题就不要多次尝试，这个时候就因该多去思考这些问题，就是问题的边界是什么，能怎么解决什么的
- 其次，就是做事不能拖，就算要拖，也得记住之后会做这五件事，我就是因为这种想法导致了之前的挂科，虽然底层可能不是因为拖延，但是这种态度不好
- 最后就是，自己设定一个问题时，要设定一个时间边界，如果超出了这个时间边界的时候呢，就可以思考，能不能有一个最简单，最便捷 的方法能够完成这件事情，如果没有，就暂时放弃这件事，有的话就立即做，比如我今天这件事最优的方法就是直接代码，然后打电话问，这是最快的，也是最不用动脑子的，可能是因为我自己想要一劳永逸的解决这个问题，所以就会选择逃避这个问题。
