## 使用

> 目前我每次打开他需要打开存的文件地址，然后用vs code 打开
>
> - 激活虚拟环境
>
>   - venv\Scripts\activate
>
>   - > 这里是windows系统里面如何创建虚拟环境的方法
>
> - pip安装（就看文档教程）
>
>   - pip list看安装了什么
>
> -  创建站点
>
>   - > mkdocs new (名字)
>
> - **启动站点**
>
>   > **mkdocs serve**
>   >
>   > 恭喜你有了自己的网址了
>   >
>   > 默认调用8000窗口
>
>  - 看教程配置主题

也是能正式使用了，不错不错，有成果的时候再去考虑怎么去*上网*,提一下,当然在那之前学一下 GitHub 的基础功能,计算机大学生不会用 GitHub (恼)

- 同步问题：
	- 平板端和电脑端：使用 easy sync插件，用于同步两边的信息
	- 博客和 obsidian：用 powershell 文件写，并在其中输入一下命令

~~~
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\MyBlog\scripts\sync-notes.ps1"
~~~


- 合并操作（以后不要用这个，因为框架已经好了，这是改框架用的）

~~~
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\MyBlog\scripts\merge-docs.ps1"
~~~
