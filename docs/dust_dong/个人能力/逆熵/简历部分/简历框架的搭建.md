## 自己的话

	为什么要写简历，无非就几个目的，对自己的规划————一个比较明确的发展方向；求职，就是向公司展示自己。无论是规划还是求职，都与能力相关，一个是你想要什么能力，一个是你有什么能力。
	基于能力，自媒体和 AI 都是必备的，因为一个是杠杆，一个是增效的，前者需要有敏锐度，就是对数据，还有观众喜欢什么，怎么影响观众情绪之类的东西，有了这些敏锐度，就很容易去扩大自己的影响力，AI 能提效就举我自己的例子，就是我个人博客用的 mkdocs 搭建，之前看官方文档花了几个小时才勉强搭好本地的，但是想要托管上网还有学 git 和 github action，这些我就一直拖延，不想，就导致一直在本地，但是大二上学期了解了一些知识，但是觉得很麻烦，把提示词放进去，DSH 不到 30 分钟就搭好了，甚至我想要他给我一个 obsidian 画布都给我自动生成了，我后续一定要去优化这个画布，因为我 Python 还没学完。这种 AI 的提效的例子很深入我心，但是没有基础不好优化。
	除了基础能力，还有两个大方向的能力，一个是对外，一个是对内，对外就是向其他人或者组织展示，这包含社交能力，社交能力意味者你能引导话题的发展，不一定话最多的是你，而一定是你能让所有人感到舒服，达到了这一层想传递价值就好很多了，这就引申到商务能力，但是传递价值的前提就是你首先得有价值，在这里称为业务能力，举个我身边的例子，隔壁初创的网安实验室负责人项目工程能力超强，做了很多项目，也打了很多比赛，他如果想和其他实验室谈合作就会比较轻松，相对与我们，我们 OSCA 类似于初创，但是我个人认为我门有点半吊子了，也就是因为这个，目前的负责人想和其他实验室谈合作想不到或者还在做一些事情来交换价值。
	对内就是自我的内容，主要针对大学生，包括学业和职业，学业首先就是专业内容，其次就是规划，专业内容有要考虑分数对未来的影响，比如出国保研什么的可能比较看中这些，能写进简历的有奖学金，因为这是直接的体现，我挂了一科所以不考虑了大概 70-80 分就行，因为想过考试还是很简单的，但是智能科学与技术专业就是那种啥都学，啥都学不精的那种，对于我，找到一个比较适合或者喜欢的方向才是最重要的，讽刺的是，我一直在干别的事。规划也算学业，因为本科毕业无非就是工作，升学嘛，如果要升学，又要看想考什么学校什么专业，需要付出什么精力之类的，可惜的是就是不能和上任考了三次最后到中科大的学长交流，因为他有点心理问题，上岸后把我们全拉黑了，可以从侧面看这位学长的升学规划不太合理，因为把自己整出抑郁症了，但能坚持也是很强的，升研还有一个很重要的点就是导师，就说上面那位三战的学长，他经常会去一些会议，主要是计算机类的，他的主要目的就是看有那些是学校的老师，而那些是自己喜欢专业方向的老师，就只要去询问和链接他们，也是一个很有价值的参考
	刚才说了，除了升学就是就业，就业就涉及到自我的另一个方向：职业，要了解职业的话要从无壁垒的了解职业信息，职业需要什么技能，需要什么经验，以及做这个职业什么该做，什么不该做之类的，这些都是需要了解的方向
	要积极去探索，我知道对于我自己会有点痛苦，但是逃避永远无法带来成长，而我不能成长又是给我的长期痛苦（大一下一学期我已经深深体会到了），比如大体上，社会的职业有自媒体，科研，泛商科，创业，产品这几个领域，可以跨领域但是不能占用你的主线时间，比如我想搞自媒体，所以我去了合伙人，但是我又放不下专业内容，因为我想成为技术很 NB 的码农，事实上这两个都是需要很多时间才能成的，那段时间我的管理完全是混乱的，导致都没做好，没成为编程大手子也没样养成自媒体思维，导致我现在很迷茫，因为学的很乱，并且很浅，很多需要学的又入手不了（有门槛，这里指计算机类），所以探索要先在一个大方向，不能两个大方向
	扯回来，自媒体是关于价值的流通，本身不生产价值，但是能够想到如何看到一个选题，观众有什么反应并且实际上就是这么做的，基本上就入门了自媒体，运营和自媒体类似，科研就是创造价值，自己的话就是从无到有，而这个有能帮到别人，可以说黄仁勋也是，因为他带领公司开发芯片，而这个芯片影响到了未来 AI 的发展。创业的话就是这几个领域的总和，我的理解就是成为一个通才，但是在某一个方向上有一点突出
	前面描述了对内对外的能力要求和一些领域，这些都是对简历有用的前置信息，这里开始将很重要的一点，就是经历，首先就是上面说的不要在其他领域花太多时间，在这基础上整合一下经历构成，也是向内和向外，向内就是校内，校内的经历无非就是，成绩，这个不好说，因为盖哥描述造假的很多，而且企业不查，没试过，不能验证这个的真实性；还有科研，这是业务能力的体现，和老师做了什么项目，这个项目是否能够和你应聘的公司的工作相匹配之类的，这也是一个很重要的纬度评估你的专业性；最后就是作品，放在我这就是做了什么项目，可能算自己做的把，最近比较迷茫，不知道找什么，想谁便找一个又怕浪费时间，这就是目标不清晰的后果，我大一下痛苦为什么不去探索这个呢，偏要等到事情变得严重。
	之后就是校外，实习，项目，创业，比赛，这首适应能力和执行力的体现，不要为了能填简历而盲目的去参加竞赛，要为了能培养什么能力，这里我就感觉有点矛盾，想的比较清楚做能更好，但是做的反馈之后再去想才会更好

	- 要去交逆熵的作业，就算赶不上这个过程一定要用心
- 其次就是科学的调研咱们智能科学与技术专业能干什么学什么，做什么职业，需要什么素养，感兴趣的就去做，做完再去反馈，搞笑的是我一直把专业不一定需要对口还否定我的学习
	- 方向的话一些可以结合自己的作业，就是工程概论要编一个图形界面，这个也是一个项目
