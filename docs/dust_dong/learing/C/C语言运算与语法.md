###### 算术运算符
- +
- -
- *
- /
- %（取模）
	- 简单来说就是相除取余数（强调一下只能用整型，不能用浮点数）
> 下面这两个平时最好别用，只在循环上用就行，其他地方用容易把人搞蒙
	主要理解一点，这两个分为前缀和后缀，并且与单纯的 +1-1 是不一样的
	前缀的话是先把右值变大或缩小再赋值，而后缀是先赋值再将右值变大或缩小

- **++** 
~~~ c
int32_t value = 5;
int32_t result;

result = value++; // 先将 value 的值（5）赋给 result ——>  将 value 变为 6
// 这里输出的结果是 result = 5; value = 6;
value = 5;

result = ++value; // 先将 value 变为 6 --> 然后将 value 的值赋给 result
// result 和 value 都是 6
//当然,如果理解 ++ 为本身进行了一次 +1 的隐藏的运算也是可以的,主要是区别是先赋值还是先改变数据
~~~
- **--**  
~~~ c
//默认值同 ++
result = value--;

value = 5;

result = --value;
\\解释方式和上面一样
~~~

###### 赋值运算符
> C 语言一般都是从右往左看，问就是语言特性，我们常把赋值的过程比作将东西装入容器里的过程，所以这里也用这种理解方式

- =
	- 数据对象
		- 可以理解为容器
	- 左值
		- 容器名称，就是变量名
	- 右值
		- 右边的数据
	- 运算符
		- 右值对左值产生的行为

多重赋值：

~~~ c
int32_t x, y, z;
x = y = z = 10;
//  依旧从右往左，先是 10 赋值给 z ，z 赋值给 y, y 赋值给 x
~~~
为了==可读性==尽量不要有三重以上的赋值，定义也是

#### 语法
 ###### 决策控制
**if** :
~~~ c
#include <stdio.h>

int main(void){
	int number = 10;
	
	if (number > 10){
		printf("the number > 10\n");
	}
	else{
		printf("the number !> 10\n");
	}
	return 0;
}
~~~

简单来说就是判断是否满足 if （条件）里的条件，满足条件（为真），就执行，不满足就继续向下运行程序或者执行 else 的内容
对于==不带大括号==的情况，无论是 if 还是 else 都只读取最近的一行**代码**，超出最近的那一行视为正常的代码块，多个 else 只匹配最近的那个 if ,举个例子：

~~~ c
if（number = 10)
	printf("number = 10");
else
	printf("number not 10");
	printf("1111");
	
// 等价于：
if（number = 10){
	printf("number = 10");
}
else{
	printf("number not 10");
}

printf("1111"); //超出的那一行当作正常代码执行
~~~

**else if**：
相当于多重判断，if 不满足才去判断 else if（有更多的选择）
都不满足的话就执行 else ；
> 这部分主要是去刷,因该说是去应用,理论的知识不多

 **if 嵌套**：

 不建议用，容易搞乱逻辑
 在企业中有东西可以避免这个，像 [策略模式](https://www.runoob.com/design-pattern/strategy-pattern.html) （这个主要是面相对象的编程思维）

**if-else 短路问题**；

> if else 最大的问题就是需要判断一个非常复杂的问题，就很容易出现遇到一些特定的问题卡在第一行了，这里用的方法是使用与或运算来减少运算过程
