> 相对与 leetcode，这一篇文档的这道题超级简单，但我相信在理解了思路之后能够对 if 逻辑判断，switch 的作用有了入门级的理解

**题目**：

公司的文件访问需要要权限，需要一个程序能够判断该个体是否拥有权限，权限获取要求如下：
- 经理：可以直接访问所有文件
- 员工：完成相应 5 个工作方可访问文件
- 实习生：完成 10 个工作同时获得经理的许可方可访问

**思考**：

- 程序的输入：
	- 身份、工作量、许可
	- 这些都能用一些输入的函数实现
- 处理：
	- 判断
	- if-else 判断
	- 还是用 switch 来处理不同的身份再判断
	- 写 bool 函数判断，里面调用
- 输出：
	- 是否能访问
	- 没有什么其他要求简单输出就行
